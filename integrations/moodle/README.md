# Adapter Moodle

`mod_uckkarchive/` est l’adapter Moodle partagé de l’Engine Médiathèque. Il n’est pas une instance et ne possède pas une Médiathèque particulière.

Les dossiers d’instance (`mediatheque-uckk/`, `mediatheque-universite-math/`, etc.) sélectionnent cet adapter et fournissent leur `sitekey`/configuration. Les données restent dans le backend Moodle correspondant.
